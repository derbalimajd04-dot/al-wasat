# Design System Master File — AL WASAT

> **LOGIC:** When building a specific page, first check `design-system/al-wasat/pages/[page-name].md`.
> If that file exists, its rules **override** this Master file.
> If not, strictly follow the rules below.

**Project:** AL WASAT — premium Tunisian extra virgin olive oil
**Category:** E-commerce Luxury (heritage / agricultural)
**Stack:** Static HTML + CSS + vanilla JS — no framework, no build step
**Source of truth in code:** the `:root` token block at the top of `styles.css`

> Generated by `ui-ux-pro-max --design-system --persist`, then **reconciled
> against the shipped build**. The generator optimises toward a light-mode,
> framework-ish default; five of its recommendations were rejected for this
> brand. Each rejection is recorded with its reason, so the divergence is a
> decision on record rather than silent drift.

---

## 1. Colour

Dark ground with an ivory counterweight. Gold is an **accent**, never a
default. The ivory is taken from the product photography itself — olive-glass
bottle, gold cap, marble ground — which is why the light band and the product
shots sit together without a seam.

| Role | Token | Value | Contrast on its ground |
|---|---|---|---|
| Page ground | `--ink` | `#0A0906` | — |
| Raised band | `--ink2` | `#151210` | — |
| Light band | `--ivory` | `#F2ECE0` | — |
| Primary text | `--cream` | `#F5F0E8` | 17.6:1 |
| Heading text | `--cream2` | `#EDE5D4` | 15.9:1 |
| Secondary text | `--stone2` | `#B4A896` | 8.5:1 |
| Tertiary text | `--stone` | `#988D7C` | 6.1:1 |
| **Accent** | `--gold` | `#C9A96E` | 8.9:1 |
| Ivory — heading | `--olive-ink` | `#232A18` | 12.6:1 |
| Ivory — body | `--olive` | `#3D4A2A` | 8.1:1 |

Alpha variants are tokenised as channels, never re-hardcoded:

```css
--gold-rgb: 201 169 110;
--line:   rgb(var(--gold-rgb) / 0.10);   /* hairline  */
--line-2: rgb(var(--gold-rgb) / 0.18);   /* border    */
--wash:   rgb(var(--gold-rgb) / 0.04);   /* hover bed */
```

**Gold is reserved for price, primary CTA, and proof numbers.** Nothing else.
Decorative numerals — stats, timeline years, step numbers — use `--cream` at
low alpha. This rule exists because gold-everywhere is exactly what stopped
important elements from standing out.

> **DIVERGENCE — palette.** Generator proposed `#FAFAF9` background /
> `#0C0A09` foreground, i.e. light mode. The brand requires a dark premium
> ground. Adapted to dark-first with an ivory band rather than inverting.
>
> **DIVERGENCE — accent.** Generator proposed `#A16207`, tuned for 3:1
> against **white**. On this dark ground the brand gold `#C9A96E` reaches
> **8.9:1** — both more on-brand and more accessible *in this context*. Kept.

## 2. Typography

- **Display / headings:** Playfair Display — *confirmed by the generator and
  by both typography-domain results*
- **Body:** EB Garamond
- **Labels / UI:** Tenor Sans, uppercase, tracked

> **DIVERGENCE — body font.** Generator proposed **Inter**. Rejected. The
> skill's own typography domain, queried for `"editorial heritage luxury
> serif"`, returns as its top result a pairing whose note reads: *"NO UI
> sans-serif — 100% serif/mono."* An editorial heritage brand is served by a
> serif body; Inter would flatten it toward generic DTC. EB Garamond retained.

### Scale — 12px floor

Nothing a customer must read renders below 12px.

```css
--fs-micro:0.75rem;    /* 12px — smallest legible label */
--fs-label:0.8125rem;  /* 13px — nav, kickers, meta     */
--fs-body-s:0.9375rem; /* 15px — dense body             */
--fs-body:1rem;        /* 16px — body baseline          */
--fs-body-l:1.125rem;  /* 18px — lead paragraphs        */
--fs-h4:1.375rem;   --fs-h3:1.75rem;
--fs-h2:clamp(2rem,3.4vw,2.75rem);
--fs-h1:clamp(2.6rem,4.4vw,4rem);
```

**Tracking rule.** The luxury character of the caps comes from *uppercase +
tracking*, not from being small. When sizes were raised to the floor, tracking
was pulled down proportionally (×0.78 above 0.28em, ×0.85 above 0.20em) so the
labels read as confident rather than bulky.

**Italic rule.** Italic marks emphasis and pull-quotes only. Running body text
is roman — long italic serif paragraphs look premium but resist scanning.

## 3. Style

**Restrained editorial.** Flat surfaces, hairline rules, square corners,
generous whitespace, one photographic subject per viewport.

> **DIVERGENCE — style.** Generator proposed **"Liquid Glass"** — morphing
> elements, 400–600ms fluid animations, dynamic blur, chromatic aberration.
> Rejected on three grounds:
> 1. It contradicts the brief; the explicit ask was *less* visual noise.
> 2. The generator's own output flags it `Performance ⚠ Moderate-Poor` and
>    `Accessibility ⚠ Text contrast`.
> 3. It reads as tech/SaaS. This is a sixty-year-old agricultural house.
>
> **DIVERGENCE — component specs.** Generator's button spec uses
> `border-radius:8px`, `font-weight:600`, `translateY(-1px)` on hover. This
> brand is square-cornered, light-weight (300–400) and letterspaced, and
> hover must not shift layout bounds. Use the shipped `.btn-primary` instead.

**Removed deliberately — do not reintroduce:** marquee, custom cursor, hero
frame lines, scroll indicator, ambient radial glows, gold `text-shadow` on
headings, GSAP page transitions. Grain retained at `0.015` opacity.

### Motion

```css
--ease:cubic-bezier(0.16,1,0.3,1);
--dur-fast:0.18s;  --dur:0.3s;  --dur-slow:0.45s;
```

Micro-interactions 150–300ms. `prefers-reduced-motion` must land animated-in
elements in their **final** state — killing an entrance animation without this
leaves content permanently invisible.

## 4. Spacing

4px rhythm, `--sp-1` `0.25rem` → `--sp-10` `7rem`. (Supersedes the generator's
`--space-*` names; same rhythm, different tokens already in the codebase.)

## 5. Page pattern

> **DIVERGENCE — pattern.** Generator proposed *Feature-Rich Showcase*
> (Hero → Features → CTA). Too thin: a heritage brand at this price point must
> carry provenance. Expanded — while keeping the generator's correct call that
> **CTA belongs above the fold**.

```
hero            product + price + proof, CTA above fold
shop band       ivory — breaks the one-note dark
reviews         social proof adjacent to product
trust band      certifications, lab figures, named sources
heritage · process · quote · press
newsletter · contact
```

Held to 7 middle sections. Anything restating another section gets cut, not
reworded.

---

## 6. Non-negotiables

- Contrast ≥ 4.5:1 for text on **both** grounds; verify light and dark apart.
- Touch targets ≥ 44×44 on coarse pointers.
- Visible `:focus-visible` ring on every interactive element.
- Trust claims link to evidence or render as plain text — never a link that
  leads nowhere. Placeholder `#TODO…` hrefs are stripped at runtime.
- No emoji as icons; SVG only.
- `dvh` over `vh`.
- Async actions show feedback within 300ms (generator's *Loading States* rule;
  currently satisfied by the contact form and Stripe button).

---

## 7. Known debt

- ~210 duplicate selector+context pairs remain in `styles.css`. They are
  **load-bearing**: a full merge was attempted and reverted after it broke
  ~200 computed styles, because base rules moved below the grouped overrides
  that neutralise them. Removing them needs specificity + cascade-position
  analysis. The token layer removes the incentive to add more.
- 8 `#TODO` proof links await real certificate / article / lab-report URLs.
- The ivory band is homepage-only by design; extending it to the shop grid is
  an open question, not an oversight.
